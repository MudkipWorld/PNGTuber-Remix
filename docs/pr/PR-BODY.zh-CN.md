# PR 标题

为 V1.4.5 增加实验性保护模型导出与配套播放器

# PR 说明

此草稿增加保护制作端与播放端，让作者交付仍能实时运动的模型，同时限制普通编辑、工程保存和素材导出入口。**实现基于 V1.4.5（6b09389），尚未完成向当前默认分支 1.4.x 的移植，不能直接视为可合并版本。** 详见 UPSTREAM-INTEGRATION.md。

## 功能

制作端保留普通 .pngRemix 工程编辑，新增 .pngRemixProtected 导出，不改变源工程保存路径。配套播放器提供麦克风、音量阈值、透明背景、缩放和位置调整；支持状态、普通可切换资源及循环资源三个动作的键盘／鼠标绑定，并按模型保存个人设置和恢复作者原绑定。无效 Unknown 覆盖会被忽略。

播放器身份由构建特性确定，普通保存、自动备份、素材导出、编辑及远程接口在实现入口处受限制。模型数据加密封装并认证，不是删除运行所需参数，也不承诺防逆向或内存提取。

## 构建与交付边界

私密密钥由本地脚本生成，制作端和播放端必须使用同一套密钥。提交不包含生产密钥、个人设置、客户工程或构建产物。原 LICENSE 保持不变。中英文使用说明、格式文档、构建及测试指南随源码提供。

## 运动差异单独审阅

实际检查的汉化运行包与 GitHub 标签源码在五个运动脚本上有差异：四类对象触发吸附后同步重置 Dragger；拖拽改用角色局部坐标插值，而非 shadow_drag 平滑。此兼容改动独立成一个提交，并附中英文报告及样本哈希。

结论仅针对被检查的运行包，不推断所有汉化版都不同，也不推断修改者及修改时间。请求维护者决定在移植时采用、拆分或提供可选兼容行为。

## 验证与限制

自动测试覆盖容器认证、数据校验、保存／导出／网络入口、个人设置与三类绑定、鼠标修复、恢复原绑定及运动回归。示例保护导出前后 11,700 个采样最大差为 0；指定双状态工程与恢复出的本地运动脚本对比 15,840 行记录最大差为 0。私人输入不公开，公开测试使用示例和合成数据。

已进行 Windows 播放端发布加载、正常关闭和界面检查，以及制作端构建／启动检查。独立审查发现的嵌套绑定校验和设置控件不同步问题已经修正。未宣称通过当前上游分支 CI、完整安全审计、所有模型和真实设备／OBS 验收。加载失败恢复采用内存快照，尚非完整原子场景替换；已知原版无头渲染及退出诊断见验证记录。
