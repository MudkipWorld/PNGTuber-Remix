# PNGRemix 保护版使用说明

本地测试版，基于官方 V1.4.5（6b093894e33d804368367a0e98e1dc3722e4909b），Windows x64。

## 作者使用

1. 解压创作者包，保留所有 DLL，运行 `PNGRemix-Protected-creator.exe`。
2. 按原版方式打开自己的 `.pngRemix` 工程，确认模型正常。
3. 点击左上角“导出保护版 / Export protected”，保存为 `.pngRemixProtected`。
4. 给客户保护模型和本次配套的播放版文件夹。不要发送普通工程、创作者版或开发目录。

保存普通工程与导出保护版是两个操作。导出包含当前编辑状态，不改变源工程路径。保留自己的普通工程备份。

## 客户使用

1. 解压播放版完整文件夹，不要单独移动 EXE 或删除旁边的 DLL。
2. 运行 `PNGRemix-Protected-player.exe`，点击“打开保护模型 / Open model”。也可拖入一个保护模型文件。
3. 选择麦克风，滑动音量阈值，按需要勾选透明背景。
4. 下拉框选择表情。在按键输入框按一个按键或组合键，或在框内右击，为当前表情绑定个人快捷键。点击“恢复当前状态原绑定”可取消该状态的个人覆盖。
5. 鼠标滚轮缩放，按住鼠标中键或右键拖动画面。点击“保存个人设置”保存这些配置。
6. Tab 隐藏/显示控制面板。OBS 捕获该窗口；实际麦克风与 OBS 组合需要在客户电脑上确认。

个人设置按保护文件分开保存到系统用户数据目录 `PNGRemixProtected/player`。它不包含作者的模型运动参数。

## 配套要求与限制

- 保护文件只能由密钥匹配的这套播放版读取，官方原版不支持它。换一套生成密钥后，旧文件不能直接交给新播放器。
- 运行需要运动数据，保护文件将其加密封装，不是删除参数。保护针对普通操作，不承诺防逆向、内存提取、录屏或整个包的复制。
- 播放版禁止普通保存、素材导出、自动备份、编辑模式与 WebSocket。
- 当前验证主要使用官方示例模型；你的具体模型、网格、附肢、动画素材及麦克风环境还需要实际验收。不要把本地测试版描述为已覆盖所有模型。
- 官方许可证允许使用软件制作委托，但商业分发修改版软件需作者事先书面许可。本包保留原 LICENSE，未代表你取得该许可。

## 故障排查

无法加载时先确认是 `.pngRemixProtected`、使用配套播放器且文件完整。不要改后缀尝试绕过格式检查。出现不兼容提示，请回到创作者版重新导出并使用对应播放版。

若模型能显示但不响应声音，检查系统麦克风权限、所选设备和音量阈值。禁止编辑参数不影响客户调整这些设备设置。

## 最新绑定功能

状态、普通资源和循环资源均支持个人键盘／鼠标绑定与恢复原绑定。详见 [普通资源说明](asset-bindings.zh-CN.md)、[循环资源说明](cycle-bindings.zh-CN.md)。面板可滚动，Tab 显示／隐藏。重新导出的文件具有不同哈希，个人设置不会自动迁移到新文件。开发者请参阅 [构建测试指南](build-and-test.md)。
