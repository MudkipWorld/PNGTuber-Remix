# 循环资源绑定使用说明

此版包含状态绑定、普通资源绑定、循环资源绑定，以及此前的 Drag Snap 与鼠标绑定修复。

1. 打开已有保护模型，在“循环资源绑定 / Cycle bindings”中选择循环组。括号显示组内资源数量。
2. 选择要修改的动作：启用／关闭、下一个、上一个。
3. 点击输入框，按键盘按键或组合键，或在框内右击绑定鼠标右键。设置自动按模型保存。
4. 点击“恢复此循环动作原绑定”，只恢复当前循环组的当前动作，其余设置保留。

启用／关闭沿用原版行为：关闭时隐藏该组资源；重新启用时可能随机选择组内资源，并在有其他选项时避开上次资源。下一个、上一个按原循环顺序切换，并启用该组。没有循环资源时控件禁用。只有作者已创建的循环组可修改绑定，不在播放器中增删组或修改资源顺序。

面板内容超出窗口时可滚动；Tab 隐藏／显示面板。原保护模型无需重新导出。

循环的个人绑定独立保存，不改写原模型。多个动作使用相同按键可能同时触发，请为需要独立控制的动作设置不同按键。

验证：配置校验、鼠标绑定到运行时动作、保存重载、单动作恢复、循环顺序与开关行为、切换模型清理均通过自动测试。已检查界面截图、发布程序加载及正常关闭。真实设备与直播环境下的触发仍需实际使用确认。
