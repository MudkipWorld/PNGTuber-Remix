# 2026-10-18 鼠标状态快捷键修复

此播放版包含此前的 Drag Snap 兼容性修复。

本次修复：
- 忽略旧个人设置中的 Unknown 或空键值，保留模型原有的鼠标右键绑定。
- 支持在快捷键输入框内右击，给当前选中的状态绑定鼠标右键。
- 选择状态时显示当前实际绑定；新增“恢复当前状态原绑定”。
- 保留有效的旧键盘绑定，支持鼠标绑定的保存与重新加载。

使用：关闭旧播放器，解压完整新文件夹并运行 EXE。打开原保护模型即可，不需要重新导出。旧 Unknown 记录会在读取时自动忽略。若曾设置有效但不想使用的个人绑定，选择对应状态后点击“恢复当前状态原绑定”。

若要自行绑定：先在状态下拉框选择目标状态，然后在快捷键输入框内右击。不要在状态下拉框上右击，也不要把右击仅用于普通画布拖动。选择状态 1 时，应显示“鼠标右键 / Right mouse button”（前提是工程原本绑定为右键）。

验证：无效绑定回归、原鼠标动作恢复、鼠标捕获与冲突处理、个人设置保存重载及恢复原绑定均通过自动测试；发布播放器加载与正常关闭检查通过。实际物理鼠标在用户直播环境中的触发效果仍需实际使用确认。
