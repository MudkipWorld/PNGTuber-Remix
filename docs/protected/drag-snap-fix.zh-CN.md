# 2026-10-18 Drag Snap 兼容性修复

修复目标：与用户实际使用的 Windows V1.4.5 汉化版保持运动一致。

用户安装包的运动脚本与 GitHub V1.4.5 标签存在功能差异：
- Sprite、Mesh、Appendage、Comment 在状态切换触发 Drag Snap 时，安装包会同步重置 Dragger，标签源码没有。
- 安装包使用角色局部坐标中的拖拽插值；标签源码使用 shadow_drag 累积平滑，导致相同参数呈现不同效果。

本次只对齐以上五个脚本的运动差异。未改变保护格式、密钥或用户工程。

验证：
- 修复前回归测试明确失败：吸附未重置跟随点，拖拽输出与参考值不同。
- 修复后上述回归、临界阈值、不吸附哨兵值 999999 及保护格式测试通过。
- 用户当前工程含两个状态；固定 60 Hz 输入、240 帧、每 40 帧切换状态，15,840 个精灵位置/跟随点采样与从用户安装包恢复的运动脚本一致，最大差值 0。
- 该比较是固定输入的数值验证，不代表已逐项人工验收所有实时设备和渲染效果。

使用：关闭正在运行的旧程序，解压修复版完整文件夹后运行。作者使用 creator，客户使用 player。原保护模型可直接由本次 player 打开，无需重新导出。
