# 资源切换绑定使用说明

此版本包含此前的 Drag Snap 和鼠标右键绑定修复。

1. 打开原保护模型。
2. 在“资源切换绑定 / Asset bindings”下拉框选择资源，列表显示名称和 ID 以区分重名资源。
3. 点击下方输入框，按键盘按键、组合键，或在框内右击绑定鼠标右键。修改自动保存，也可点击“保存个人设置”。
4. 点击“恢复资源原绑定 / Restore asset binding”可撤销当前资源的个人覆盖。

只列出作者标记为可切换资源的项目。若显示“此模型没有可切换资源”，需在制作端将相关资源设为可切换资源，再重新导出。

播放器沿用作者的按下切换显隐、按住显示或按下显示行为；本功能仅修改主触发绑定，作者单独设置的隐藏键保持原样。多个资源使用相同按键时会共同触发，与原有资源组合用法一致；若希望分别控制，请使用不同按键。

设置按保护模型分别保存，不改写保护模型、素材或运动参数。现有可切换资源无需重新导出即可修改绑定。按 Tab 隐藏或显示面板。

验证：鼠标与键盘配置校验、实际 InputMap 动作更新、偏好保存重载、原绑定恢复、作者数据保持和切换模型清理已通过自动测试。实际鼠标及全局快捷键在用户直播环境中的表现需实际使用确认。
