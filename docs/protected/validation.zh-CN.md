# 本地验证记录（2026-10-17）

基线：PNGTuber-Remix V1.4.5，6b093894e33d804368367a0e98e1dc3722e4909b。构建工具：Godot 4.6 stable，Windows x64。

## 已验证
- `tools/test-protected.ps1` 通过：AES 测试向量、认证与篡改/截断拒绝、数据类型与图片检查、官方示例导出/加载、禁止编辑/普通保存/备份/素材导出/WebSocket、个人设置白名单与快捷键冲突回归。
- 同一示例经过原模型与保护模型路径运行固定运动输入，11,700 个采样，最大差值 0。
- 发布播放器使用实际 OpenGL 与 WASAPI 启动，加载含中文和空格路径的保护模型成功；发送正常窗口关闭消息后退出码 0。
- 开发版界面截图已检查：模型显示，编辑面板隐藏。
- 独立代码审查提出的类型检查、快捷键冲突、读取前头部校验三项问题已修复并纳入回归测试。

## 验证边界
- 尚未用用户自己的模型验收；未完整覆盖网格、附肢、动画图片、实时麦克风输入、OBS、全部原生文件对话框和干净电脑环境。
- 运行期构建失败采用内存快照恢复，不是完整的场景原子替换；恢复可能重置动画相位。未完成所有运行期异常的故障注入验证。
- 无头测试存在原版同样出现的三条 shader dummy renderer 诊断及 ObjectDB 退出泄漏警告。
- 强制引擎 `--quit-after` 的带音频退出曾出现访问异常，原版也复现；正常窗口关闭已验证成功。不要以自动计时退出结果替代正常用户关闭路径。
- 运动数据加密封装；运行时仍需解密，不能承诺防逆向提取。

## 再构建
保留 `Protected/generated/BuildKeys.gd` 的私密备份；不要发送给客户。首次没有密钥时运行 `tools/new-protected-keys.ps1`，然后分别执行 `tools/build-protected.ps1 -Role creator` 与 `-Role player`。两端必须使用同一套密钥。构建需要 Godot 4.6 及对应 Windows 导出模板；通过 -GodotPath 或 GODOT_PATH 指定 Godot；通过 -TemplateDir 指定模板目录。
